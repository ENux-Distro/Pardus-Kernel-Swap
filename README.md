# Pardus-Kernel-Swap

In order to run this kernel swap program, you need to do these:
 - Git clone the repository via `sudo apt install git && git clone --depth 1 https://github.com/ENux-Distro/Pardus-Kernel-Swap.git`
 - Change your directory onto the git cloned directory via `cd /path/to/Pardus-Kernel-Swap`
 - Run the kernel swap program via `sudo bash swap`

After everything has went succesfully, reboot and enjoy your swapped kernel
